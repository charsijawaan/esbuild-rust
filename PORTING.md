# Experimental porting status

This is an experimental AI-agent conversion of esbuild to Rust. All Rust port
code is LLM-generated by OpenAI Codex agents using GPT-5.6 Sol. It is
unaudited, incomplete, and not an official esbuild project.

The current compiler feature checkpoint is `1e048eb`, against upstream commit
`6ff1d8b0d8c134e867a397eef39702a223ebef9e` (esbuild 0.28.1).

Two deliberately separate engineering estimates are used:

- **About 71.3% of the whole esbuild product surface.** This includes the
  compiler, native API and CLI as well as serve, the long-running service
  protocol, JavaScript and Go API wrappers, WebAssembly, npm packages, and
  distribution tooling.
- **About 98.6% of the selected native compiler/bundler/API core.** This
  narrower estimate covers parsing, printing, resolution, linking, bundling,
  transformation, source maps, minification, native plugins, and native build
  contexts.

These are judgment-based progress estimates, not line coverage or an official
upstream compatibility metric. They are intentionally capped by known missing
features and by the absence of exhaustive upstream conformance and performance
testing. See [EVALUATION.md](EVALUATION.md) for the reproducible release-binary
matrix.

At this checkpoint the repository contains 108,812 physical lines across its
tracked `*.rs` files and 837 passing Rust tests. The bounded differential
evaluator passes 12 of 12 scenarios with the same runtime results as pinned
upstream.

Status values:

- `not started`: no Rust implementation
- `in progress`: some source files translated, parity incomplete
- `ported`: source translated and focused parity tests pass
- `verified`: package-level and integration parity tests pass

## Material work still outside the checkpoint

- Serve and the JavaScript/Go service protocol are not Rust ports.
- WebAssembly, npm package wrappers, platform packages, and release tooling are
  not ported.
- The native context API supports rebuild and watch, but context cancellation
  and CLI watch/serve parity remain incomplete.
- Native plugins cover setup, resolve/load, lifecycle callbacks, nested
  resolution, plugin data, and watch paths; the upstream JavaScript plugin host
  and protocol integration remain outside this repository.
- Some public build/transform controls are still absent, including injection,
  property mangling and mangle caches, and portions of logging/path control.
- Known compiler gaps include explicit resource-management lowering, standard
  decorators, import-glob bundling, and advanced CSS color/gradient behavior.
- The full upstream test corpus, cross-platform filesystem matrix, security
  review, and performance benchmarks have not been completed.
